## How to Analyze Winning Websites

### Deconstruction Framework

When studying any great website, document:

**1. First Impression**
- What's the immediate emotional response?
- What's the single most prominent element?
- What's the value proposition statement?

**2. Color System**
- Identify primary, secondary, neutral colors
- Note color-to-function mapping (what's CTA color vs background?)
- Check dark mode if available
- Measure contrast ratios (use browser dev tools)

**3. Typography**
- Identify font families (use WhatFont or browser inspector)
- Note size scale (headline, body, small)
- Check line height and spacing
- Identify font loading strategy

**4. Layout Architecture**
- Grid system (columns, gutters, margins)
- Content width (pixel or ch based?)
- Section spacing
- How does layout change at breakpoints?

**5. Animation System**
- Types of animations (entrance, hover, scroll, transition)
- Duration and easing
- What triggers animations?
- Performance (does it stay at 60fps?)

**6. Content Hierarchy**
- What's the headline hierarchy from H1 to body?
- How are features organized?
- What's the narrative flow?
- How is social proof presented?

**7. Interactive Elements**
- Hover states and effects
- Click/ tap feedback
- Scroll interactions
- Forms and input states

**8. Conversion Points**
- Where are CTAs placed?
- What's the CTA copy?
- Trust signals near CTAs
- Form design

## How to Identify Trends

### Trend Detection Method
1. Browse 20+ recent Awwwards winners
2. Note recurring patterns (colors, layouts, animations)
3. Check Dribbble popular shots (current month)
4. Read design trend articles (search "web design trends 2026")
5. Look at redesigned products (Stripe, Linear, Notion — what they changed)
6. Identify 3-5 patterns that appear across multiple sources

### Trend Categories to Monitor
- **Color** — New palette directions
- **Typography** — New font families or styles
- **Layout** — New grid patterns, section structures
- **Interaction** — New animation or gesture patterns
- **Technology** — New tools (WebGPU, CSS features)
- **UX** — New user experience patterns

## How to Combine Ideas Creatively

### The Creative Combination Method

**Step 1: Collect**
Gather 10+ inspiring examples from different sources

**Step 2: Extract**
Break each into components (color, layout, typography, interaction, copy)

**Step 3: Map**
Create a matrix of components:

```
        Design A   Design B   Design C
Color   [x]        [x]        [x]
Layout  [x]        [x]        [x]
Font    [x]        [x]        [x]
Anim    [x]        [x]        [x]
```

**Step 4: Combine**
Mix components from different designs into new combinations:
- Layout from A + Colors from B + Font from C
- Color system from D + Animation from A + Layout from B

**Step 5: Adapt**
Make the combination work for YOUR brand, content, and audience.
- Change colors to match brand
- Scale animations for performance
- Simplify for mobile
- Adjust for content density

### Rules for Ethical Inspiration

- **Steal like an artist** — Take concepts, not copies
- **Combine multiple sources** — One source = copy, five sources = original
- **Adapt, don't adopt** — Make it work for your specific context
- **Understand why, not just what** — Understand the reasoning behind patterns
- **Add your own twist** — Your unique perspective makes it original
- **Credit when appropriate** — If heavily inspired, acknowledge

## Competitive Analysis Method

### What to Analyze
For each competitor (3-5 max):

**1. Homepage**
- Value proposition clarity
- Visual quality
- Speed to understanding
- Quality of social proof

**2. Features/ Product**
- How they explain features
- Screenshot/ demo quality
- Feature depth vs simplicity

**3. Pricing**
- Pricing structure
- How they present value
- What tiers exist

**4. Content**
- Blog quality and frequency
- Case studies depth
- Documentation quality

**5. UX**
- Navigation structure
- Onboarding experience
- Mobile experience

### Analysis Questions
1. What do competitors do well that we don't?
2. What do we do better than competitors?
3. What opportunities are competitors missing?
4. What patterns are all competitors following (opportunity to break away)?
5. What complaints do competitor customers have (opportunity to solve)?
6. Where is the market heading (where should we invest)?
