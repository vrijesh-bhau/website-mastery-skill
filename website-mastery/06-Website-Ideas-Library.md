# 06 — Website Ideas Library

## How to Use This Library

Each idea includes:
- **Audience** — Who the site serves
- **Goal** — Primary purpose
- **Layout** — Recommended page structure
- **Sections** — Key page sections
- **UI Patterns** — Best interaction patterns
- **Colors** — Recommended palette
- **Typography** — Font pairing suggestion
- **Animations** — Motion recommendations
- **Conversion** — How to drive action
- **Mobile** — Mobile-specific considerations
- **Premium** — Ideas to elevate the design
