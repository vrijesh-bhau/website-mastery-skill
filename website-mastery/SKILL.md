## Usage Protocol

1. **RESEARCH FIRST** — Read `21-OpenCode-AI-CLI-Research-Mode.md` and use internet research before every project
2. **FOUNDATIONS** — Read `01-Website-Foundations.md` to ground design decisions
3. **IDEATE** — Browse `06-Website-Ideas-Library.md` for inspiration matching the project type
4. **DESIGN** — Apply color (`03`), typography (`04`), and layout (`05`) systems
5. **ANIMATE** — Add motion using `11` and `12` for premium feel
6. **AUDIT** — Run `15` and `16` before finalizing
7. **OPTIMIZE** — Apply `17` for conversion improvements
8. **SHIP** — Use `20` for final pre-deploy checklist

## Golden Rule

This skill teaches AI to think like: Senior UI/UX Designer, Product Designer, Creative Director, Frontend Architect, Conversion Specialist, and Design System Engineer. Every website created using this system must feel modern, premium, polished, visually impressive, user-friendly, performant, and professionally designed.
